#  Decathlon Sales Analysis Dashboard

## Project Overview

This project is an **interactive Sales Analysis Dashboard created using Microsoft Excel**.

The objective of this project was to transform raw sales data into a structured and interactive dashboard that can be used to analyze sales performance, revenue, profit, products, categories, sales channels, payment methods, customer information, and returns.

The project demonstrates the complete data analysis workflow, starting from raw data preparation and cleaning through data transformation, analysis, visualization, KPI creation, and dashboard development.

> **Important Data Disclaimer**
>
> This project **does NOT use real Decathlon company data** and is **not affiliated with or endorsed by Decathlon**.
>
> The dataset used in this project is **fictional/synthetic data created specifically for this portfolio project and dashboard development**. It was created for learning, demonstration, and data-analysis practice purposes only.
>
> No confidential, proprietary, or real company data has been used.

The main objectives of this project were to:

## 1️⃣ Data Cleaning & Preparation

The raw dataset was reviewed and prepared before performing the analysis.

The main preparation activities included:

* Reviewing the available columns
* Identifying relevant and irrelevant fields
* Removing unnecessary columns from the analysis dataset
* Checking the structure and consistency of the data
* Formatting the required fields
* Preparing date-related information for analysis
* Creating additional columns required for analysis
* Preparing revenue and profit-related fields
* Checking the final dataset before creating Pivot Tables

The objective was to ensure that the dataset was properly structured before beginning the analysis.

#  Key Findings

The analysis produced several useful observations from the fictional dataset.

### Category Performance

The **Outdoor** category generated the highest revenue among the five categories.

Revenue by category:

| Category   |    Revenue |
| ---------- | ---------: |
| Outdoor    | ₹1,621,835 |
| Sports     | ₹1,021,570 |
| Footwear   |   ₹921,678 |
| Fitness    |   ₹685,380 |
| Sportswear |   ₹380,494 |

### Product Performance

**Tent** was the highest-revenue product in the dataset, followed by Backpack, Running Shoes, and Dumbbells.

Top products by revenue included:

| Product       |    Revenue |
| ------------- | ---------: |
| Tent          | ₹1,089,285 |
| Backpack      |   ₹532,550 |
| Running Shoes |   ₹514,269 |
| Dumbbells     |   ₹503,835 |
| Casual Shoes  |   ₹407,409 |

### Profit Performance

The total profit generated across the dataset was:

**₹1,414,800**

The Outdoor category generated the highest total profit among the categories.
